## 🛠️ Getting Started

### Prerequisites
* Java Development Kit (JDK 8 or higher) installed on your local machine.

### Compilation and Execution
```bash
# Navigate to a folder
cd sortingAlgo

# Compile the Java file
javac CoreSorting.java

# Run the program
java CoreSorting
